# Ornerede Browser

Ornerede is an open-source web browser that's private and built with C++.

## Features

- C++ application
- Cross-platform goals
- Cannot Render Javascript on pages

## Supported Platforms

- Linux
- ChromeOS (PWA app)
- Windows
- macOS
