# Ornerede Browser

Ornerede is an open-source web browser powered by Mozilla Gecko and built with C++.

It is designed to be installed and launched through terminal commands.

## Features

- Mozilla Gecko rendering engine
- C++ application
- Terminal-based installation
- Cross-platform goals

## Supported Platforms

- Linux
- Android (Termux)
- Windows
- macOS

## Building

Requirements:
- C++ compiler
- CMake

```bash
cmake -S . -B build
cmake --build build
```

## Running

```bash
./build/ornerede
```
